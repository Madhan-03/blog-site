# Blog Site with Comment Section

A responsive web-based blogging platform that allows users to create, publish, and manage blog posts while enabling readers to interact through an engaging comment section.

This project demonstrates CRUD operations, dynamic comment handling, comment likes, timestamps, and responsive front-end web development.

## 📌 Project Overview

The **Blog Site with Comment Section** is designed to provide users with a simple and interactive platform for publishing and discussing blog content.

Authors can create and manage blog posts, while readers can engage through comments, react to discussions using likes, and view the exact date and time when comments were posted.

This project showcases practical implementation of:

* Blog Post CRUD Operations.
* Dynamic Comment Management.
* Comment Like System.
* Comment Delete System.
* Comment Date & Time Tracking.
* Responsive UI/UX Design.
* User Interaction and Content Organization.

---

## ❗ Problem Statement

Many blogging platforms are either too complex, require paid hosting, or offer limited customization options.

This project addresses those challenges by providing:

* A lightweight and customizable blogging platform.
* Integrated comment functionality for user engagement.
* Comment reaction (Like) feature.
* Delete Comment feature.
* Timestamp tracking for comments.
* A beginner-friendly and accessible blogging experience.

---

## 🎯 Objectives

* Develop a fully functional blog application.
* Implement Blog CRUD operations.
* Enable users to post and manage comments.
* Allow users to like comments.
